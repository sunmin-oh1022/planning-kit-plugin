## 2026-07-13 · releasekit-onepager.html (설명 원페이저)

**대상 독자 확정: 릴리스킷을 처음 보는 사람 대상 안내·설득용** — 이 전제에서 아래 [마찰]·기억 부담 항목의 심각도가 올라간다(신규자는 문서 밖 지식에 기댈 수 없으므로).

**참고 — 제품명 변경 예정:** 이 키트의 이름을 **ReleaseKit → servicekit** 으로 변경 예정. 따라서 아래 "이름 표기 불일치" 발견은 ReleaseKit/릴리스킷 중 택일이 아니라 **servicekit 으로 통일**하는 방향으로 해소한다.

### 총평
독자 과제("스타터킷 위에 무엇을 더하는지 + 한 바퀴가 어떻게 도는지 이해")에는 대체로 도달. 절차 A/B 대비와 사람·AI 경계 strip이 핵심 개념을 시각으로 못 박아 강점. 다만 한 페이지에 서로 다른 '다섯'이 두 번 등장해 개념 모델이 미세 충돌하고, 다 읽은 신규 독자에게 "어디서 시작하나"의 다음 행동이 비어 있다.

### 발견 사항
- **[마찰] 한 페이지에 '다섯'이 두 벌 — 개념 모델 충돌(A).** §01 "다섯 가지 레이어" ↔ §03 "STEP 1–5". 같은 기수(5)로 은유 충돌 → 레이어=스텝 오매핑, 재독 유발. → §03 스텝을 무번호 화살표 흐름으로, §01만 번호 유지(스캔성 손실 최소).
- **[마찰] 독자의 다음 행동 부재 — 선제적 도움(G).** 신규 독자가 형성하는 "그래서 어디서 시작?"에 답이 없음. → roles-strip 근처에 진입점 한 줄(예: "시작: README → 첫 도메인은 _template 복사"). 비용: 인쇄 공간 3~4mm.
- **[마찰(신규자 기준 상향)] "3종/4종" 이름 미제시 — 기억 부담(E).** §02-B "3종만 올리고 4종 보존"이 어느 것인지 화면에 없음. 신규자는 문서 밖 스킬 정의를 봐야 함. → 괄호로 축약 표기(예: "3종(프로토타입·화면설계서·PDF 라벨)").
- **[개선 기회] 시스템 이미지 불일치(A).** `<title>… Two Pager</title>`인데 단일 페이지 / "v2" / 릴리스킷·ReleaseKit 혼용. → 제목 정정 + **표기를 servicekit 으로 통일**(순수 정정, 트레이드오프 없음).
- **[개선 기회] 첫인상 밀도·저대비 소형 텍스트 — 본능적 수준(H)+대비.** 7–9pt, `--mut #8E8E8E`(≈3.3:1, 본문 4.5:1 미달). → 본문 최소 대비를 `--sub #5A5A5A`(≈7:1)로, 핵심 한 줄만 12pt급 시선 진입점. 밀도(한 페이지 고정)와 상충.

### 잘된 점 (유지)
- 사람·AI roles-strip 반전(검정) 박스 — 핵심 가치 "사람×AI 경계"를 본능적 수준(H)에서 시각 인코딩.
- 절차 A/B 나란히 대비 + "혼동 금지" — 예상되는 착오(mistake) 혼동을 레이아웃 제약으로 방어(D).
- STEP 1–5에 "닉네임 변경" 구체 예시 접지 — 추상 규율을 세상 속 지식으로 내려 학습 부담(E) 완화.

### 트레이드오프 메모
핵심 축은 **밀도 vs 여백/진입 유도**. `overflow:hidden`·297mm 고정이라 CTA·3종 명시·큰 진입 문장은 공간과 맞바꿔야 함. **독자가 신규자로 확정**됐으므로 위 [마찰]·기억 부담 개선의 값어치가 밀도 유지보다 크다 — 적용 권장.
