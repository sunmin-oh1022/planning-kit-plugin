# 2026 UX 트렌드 × 노먼 이론

출처: Arin Bhowmick(SAP 최고 디자인 책임자), "2026년을 좌우할 9가지 UX 디자인 트렌드" (SAP Korea 뉴스센터, 2026.03 / 원문 Forbes 2025.12).
이 파일의 용도: 기획 대상이 AI 기능, 멀티모달, 개인화, 크로스플랫폼을 포함할 때 읽는다. 각 트렌드는 노먼 이론의 **새로운 적용 표면**이지 이론의 대체물이 아니다 — 판단 기준은 여전히 간극·개념 모델·피드백이다.

전체를 관통하는 원칙 (아티클의 결론 = 노먼의 결론): 사용자의 시간·지능·프라이버시를 존중하라. 사용자를 위해서가 아니라 **사용자와 함께** 디자인하라.

## 1. 스스로 설명하는 AI (Explainable AI)

- 트렌드: 행동 전 추론 과정 표시, 쉬운 언어의 결정 설명, 틀렸을 때 사용자가 수정 가능.
- 노먼 렌즈: AI의 불투명성은 **평가의 간극의 극단적 형태**다. "시스템이 내 프롬프트로 무엇을 만들었는지 사용자가 아는가?"는 7단계의 지각·해석·평가 단계 질문 그 자체.
- 기획 체크: AI 기능마다 (a) 무엇을 근거로 했는지 노출, (b) 결과를 사용자 언어로 설명, (c) 수정/거부 경로 제공. 설명 없는 AI 출력은 평가의 간극 [차단]급 결함으로 취급하라.

## 2. 에이전틱 UX와 인간-에이전트 생태계

- 트렌드: 마스터 에이전트가 특화 에이전트들을 조율. 디자인 대상은 에이전트 생애주기, 작업 인계, 인간 개입 시점.
- 노먼 렌즈: 위임은 7단계 중 **실행을 에이전트에 넘기는 것**이지만 목표·평가는 여전히 사용자의 것이다. 따라서 에이전트 UX의 핵심 질문: 사용자가 진행 상황을 지각·해석·평가할 수 있는가? 개입(override)의 실행 간극은 좁은가?
- 기획 체크: 에이전트 작업의 상태 가시성, 중단·회수 수단, 결과 보고의 해석 가능성, 그리고 **통제감**(행동적 수준의 유능감은 위임 상황에서도 유지되어야 한다).

## 3. 실시간 생성형 인터페이스

- 트렌드: LLM이 프롬프트별 맞춤 UI를 실시간 생성. 디자이너의 산출물은 고정 화면이 아니라 **제약 조건, 안전장치, 평가 기준**.
- 노먼 렌즈: 화면이 매번 달라지면 사용자는 일관된 시스템 이미지에서 멘탈 모델을 구축할 수 없다 — **개념 모델 일관성의 최대 시험대**. 기획자가 정의해야 할 것은 화면이 아니라 "생성돼도 변하지 않는 불변 요소"(위치, 용어, 피드백 규칙)다.
- 기획 체크: 생성형 UI에도 불변 앵커(핵심 행동의 위치·명칭, 상태 표시 규약)를 명세하라. 제약(constraints)의 설계가 화면 설계를 대체한다.

## 4. 음성·멀티모달 인터페이스

- 트렌드: 음성이 과대평가기를 지나 실용화. 행동 맥락에 따라 음성·터치·시각을 결합.
- 노먼 렌즈: 손이 바쁜 상황은 UCSD의 **활동 구조** 관점 — 사용자의 실제 활동 맥락(운전, 요리, 이동)이 입력 수단을 결정한다. 음성은 시그니파이어가 없는 인터페이스이므로 "무엇을 말할 수 있는지"의 실행 간극이 본질적 약점 — 발화 가능한 것을 알려주는 장치가 필수.
- 기획 체크: 모달리티별로 7단계를 따로 점검하라. 특히 음성의 피드백(들었는지, 이해했는지, 실행했는지)과 오류 복구.

## 5. 마이크로인터랙션 = 인터페이스의 언어

- 트렌드: 작은 애니메이션·전환이 장식이 아니라 시스템이 사용자와 소통하는 방식 그 자체.
- 노먼 렌즈: 이것은 DOET **피드백 원칙의 현대적 구현**이다. 확인 메시지를 읽게 강요하지 않고 행동을 인식시키는 것 = 지각·해석 비용이 0에 가까운 평가 간극 해소.
- 기획 체크: 상태 변화마다 마이크로인터랙션 명세를 기획 단계에서 요구하라(개발 막바지 장식이 아니라). 단, 과잉 모션은 접근성(움직임 민감도)과 충돌 — 감쇠 옵션 병행.

## 6. AR의 실용화

- 트렌드: 데모를 넘어 실제 문제 해결(구매 전 가구 배치 확인, 3D 모델 검토)에 정착.
- 노먼 렌즈: AR의 가치는 **의미적·조음적 거리의 소멸**(직접 조작의 극대화)이다. "평면 이미지보다 실제 문제를 더 잘 풀 때만 의미가 있다"는 아티클의 기준은 곧 과제 중심 원칙.
- 기획 체크: AR 도입 시 "직접 조작이 이 과제에서 정말 우월한가"를 트레이드오프로 검증하라. 기술 전시용 AR은 과제 중심 원칙 위반.

## 7. 선 넘지 않는 개인화

- 트렌드: 같은 기술이라도 사용자가 동의한 맥락(Netflix)과 몰래 추적(리타게팅 광고)의 체감은 정반대. 적응 수준의 사용자 제어권과 눈에 띄는 프라이버시 설정이 답.
- 노먼 렌즈: 개인화가 "왜 이게 보이지?"를 유발하면 시스템의 행동을 사용자가 해석할 수 없는 것 — **평가의 간극 + 개념 모델 붕괴**. 침해감은 반성적 수준(신뢰·자기 이미지)의 파괴이며, 노먼의 다크 패턴 경고와 동일 선상.
- 기획 체크: 개인화 기능마다 (a) 무엇을 기반으로 하는지 설명 가능한가, (b) 사용자가 끄거나 조절할 수 있는가, (c) 설정이 발견 가능한 위치에 있는가.

## 8. 접근성, 처음부터 내장

- 트렌드: 규정 준수 체크박스가 아니라 설계 시작점. 인지적 다양성 고려는 모두에게 이익(움직임 민감도 토글 = ADHD + 멀미 사용자 공통 수혜).
- 노먼 렌즈: 접근성은 노먼 원칙의 스트레스 테스트다 — 기억 부담 최소화(세상 속 지식), 명확한 시그니파이어, 오류 관용은 장애 여부와 무관하게 전 사용자에게 같은 방향으로 작용한다. "특수 요구"가 아니라 **보편 설계의 선행 지표**.
- 기획 체크: 접근성 항목을 QA 단계가 아닌 기획서 요구사항에 포함하라. 인지 부하·모션·대비·대체 입력을 기본 명세로.

## 9. 크로스플랫폼 연속성

- 트렌드: 모바일에서 시작 → 데스크톱에서 계속 → 태블릿에서 마무리가 의식 없이 가능해야 한다.
- 노먼 렌즈: 이것은 UCSD **활동 구조와 중단 내성의 기기 간 확장**이다. 1986년의 "중단 후 재개" 요구가 2026년에는 "기기를 바꿔도 재개"로 진화했다. 상태 저장 + 맥락 복원("어디까지 했는지")이 기기 경계를 넘어야 한다.
- 기획 체크: 핵심 플로우마다 기기 전환 시나리오를 명세하라. 전환 시 입력 보존, 진행 위치 복원, 그리고 기기별 개념 모델의 일관성.

## 리뷰 모드 적용 시

기획안에 AI·개인화·멀티모달·크로스플랫폼 요소가 있으면 위 해당 항목을 점검표에 추가로 적용하고, 발견 사항의 이론 근거에 트렌드 출처(Bhowmick, 2026)와 노먼 개념을 함께 인용하라.
