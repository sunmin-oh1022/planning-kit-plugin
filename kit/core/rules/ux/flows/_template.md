# _template.md — 플로우 UX 규칙 문서 골격

새 플로우 규칙 문서(예: `login.md`, `signup.md`)를 만들 때 이 파일을 복사해 채운다. 일곱 자리를 통일해야 [`ux-review`](../../../.claude/skills/ux-review/SKILL.md) 스킬이 항목별로 대조할 수 있다. 자리를 지우지 않고 채우지 않을 때는 "해당 없음"으로 명시한다.

플로우 라벨은 파일명(확장자 제외) 을 그대로 쓴다 — 예: `login`, `signup`, `mypage`, `payment`. SCR/FLOW 문서의 프론트매터 또는 본문에 `flow: login` 형태로 라벨을 남기면 스킬이 이 문서를 자동으로 물어 온다.

## 1. 이 플로우가 해결하는 문제
이 플로우가 사용자와 서비스 사이의 어떤 마찰을 없애는지 한두 문장으로 못 박는다. 이후 모든 규칙은 이 문장을 기준으로 정렬된다.

## 2. 필수 화면·단계
플로우가 반드시 통과해야 하는 화면과 순서. 화면마다 목적을 한 줄로 붙이고, 프로젝트의 SCR 라벨과 매핑되도록 한다.

- 화면 1 — 목적
- 화면 2 — 목적
- 화면 3 — 목적

**점검**: 이 순서를 건너뛰거나 뒤바꿔도 사용자가 도착지에 닿는가? 도달 불가라면 왜 그 순서인지 근거를 남긴다.

## 3. 필수 상태
정상 외에 반드시 그려야 하는 상태. 하나라도 빠지면 SCR 문서가 완성으로 인정받지 못한다.

- 로딩 — 진입·제출·재시도 시점 각각.
- 빈 상태 — 다음 행동을 어떻게 유도할지.
- 에러 — 사용자 조작 실패 · 서버 오류 · 네트워크 실패 각각. 사용자가 다음에 할 일이 문구에 포함되어야 한다.
- 성공 — 다음 화면 · 확인 메시지 · 되돌아가기 경로.
- 권한 거부 / 차단 — 재시도 · 우회 · 문의 경로.
- 오프라인 — 데이터 캐시 여부 · 재시도 시점.
- (플로우별 특화) — 예: 결제라면 결제 취소·중복 결제.

**점검**: 각 상태가 SCR 상태 매트릭스에 개별 행으로 존재하는가?

## 4. 시간·순서 규칙
사용자의 인내심과 관련된 수치 규칙. 프로젝트 상황에 맞춰 값을 확정한다.

- 즉각 반응: 입력 후 화면 반응까지 (기본 <0.1s).
- 진행 표시 시점: 응답이 얼마를 넘으면 스켈레톤·진행 바를 띄우는지.
- 자동 진행 금지 구간: 사용자 확인이 반드시 필요한 지점 (예: 결제 확정).
- 재시도 간격 / 재시도 횟수 상한.
- 세션 만료 정책.

**점검**: 값이 숫자로 명시되어 있는가? "빠르게"·"자연스럽게" 같은 표현이 남아 있지 않은가?

## 5. 안티 패턴
과거의 실수 · 업계에서 반복적으로 지적되는 패턴. 이 항목에 해당하는 화면·문구·상호작용은 리뷰에서 자동으로 🔴 로 뜬다.

- (예) 오류 문구에 원인만 있고 해결책이 없다.
- (예) 확인/취소 버튼의 위치·라벨이 화면마다 다르다.
- (예) 필수 정보를 여러 화면에 걸쳐 다시 묻는다.

## 6. 접근성·다국어 고려
플로우 관점에서 반드시 확인하는 축.

- 스크린리더 라벨: 각 입력 필드·버튼의 accessibilityLabel · 상태 변화 안내 (예: 오류 발생 시 알림).
- 키보드 · 스위치 컨트롤로 완주 가능 여부. 포커스 순서 · 이스케이프 경로.
- 다국어: 문구 길이 편차 · 우→좌 언어 · 통화·날짜 표기.
- 다크 모드 · 동작 줄이기.

**점검**: 이 플로우를 시각·키보드·스크린리더 각각으로 완주할 수 있는가?

## 7. 검증 체크리스트
마감 전 자체 검토 시 통과해야 할 항목. `ux-review` 스킬이 이 목록을 그대로 대조한다.

- [ ] 2절의 필수 화면·단계가 SCR 로 존재한다.
- [ ] 3절의 필수 상태가 각 화면 상태 매트릭스에 있다.
- [ ] 4절의 수치 규칙이 POL 또는 SCR 정의에 값으로 박혀 있다.
- [ ] 5절 안티 패턴에 해당하는 화면·문구가 없다.
- [ ] 6절 접근성 축이 SCR 의 접근성 섹션에 명시되어 있다.
- [ ] 문구에 "빠르게 · 자연스럽게 · 직관적으로" 류 막연한 표현이 없다.
- [ ] 이 플로우와 이어지는 다른 플로우(예: 로그인 → 마이페이지)의 진입점이 명시되어 있다.
