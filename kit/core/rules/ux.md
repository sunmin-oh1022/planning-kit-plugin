# ux.md — UX 규칙 진입점

화면을 다듬거나 사용성 결정을 검증할 때 여기서부터 들어간다. 규칙 본문은 두 갈래로 나뉜다.

- **플로우 · 플랫폼 무관 공통 원칙 8개** — [`ux/common.md`](ux/common.md).
  입력 타깃 크기 · 즉시 피드백 · 체감 속도 · 상태 디자인 · 안전 영역 · 접근성 · 플랫폼 관습 · 콘텐츠 우선.

- **플로우별 규칙** — [`ux/flows/`](ux/flows/).
  회원가입 · 로그인 · 마이페이지 · 결제 등 반복되는 플로우 단위의 필수 화면 · 상태 · 시간 규칙 · 안티 패턴 · 접근성 축.

시각 토큰은 (TODO 스타일 정의 문서), View 구조는 [`ui.md`](ui.md).

## 언제 어느 문서를 읽는가

| 상황 | 진입 문서 |
| --- | --- |
| 새 화면 · 컴포넌트를 다듬는다 | [`ux/common.md`](ux/common.md) |
| 특정 플로우(로그인 · 결제 등) 화면을 설계한다 | [`ux/flows/<플로우>.md`](ux/flows/) |
| 마감 전 사용성 점검 | `ux-review` 스킬 (이론 근거 리뷰 + 플로우 문서를 항목별로 대조) |

## 검토와 스킬

플로우 SCR/FLOW 문서에 `flow: <라벨>` 를 남겨 두면 [`ux-review`](../.claude/skills/ux-review/SKILL.md) 스킬이 해당 플로우 규칙을 자동으로 물어 마감 전 점검을 돌린다(플로우 층). 이 스킬은 이론 근거 리뷰(개념 층)도 함께 제공한다. 결과는 `docs/UX-REVIEW.md` 에 일자별로 누적된다.
