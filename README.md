# planning-kit 플러그인

Claude를 **기획 코치**로 만드는 플러그인. 설치하면 "기획 시작하자"라는 말 한마디로 프로젝트 폴더에 기획 문서 체계가 세팅되고, 이후 요구사항 정리 → 화면 확인 → 화면설계서 산출까지 코치와 대화하며 진행합니다.

## 사용법

1. 플러그인 설치 (저장 버튼 클릭)
2. 작업할 폴더를 Claude에 연결
3. "새 프로젝트 기획 시작하자"라고 말하기
4. 코치의 질문 3~5개에 답하면 셋업 완료 — 바로 첫 기획 문서 작성으로 이어집니다

## 무엇이 만들어지나

- 프로젝트 폴더에 기획 문서 틀 (정의·용어·요건·정책·화면·플로우·검증 기준)
- 프로젝트 성격에 맞는 작업 도구 (인터뷰 답변에 따라 자동 선택)
- 모든 변경은 자동 스냅샷 — "되돌려줘" 한마디로 복구

## 구성

| 구성요소 | 내용 |
| --- | --- |
| 스킬 `planning-start` | 인터뷰형 프로젝트 셋업 (시작하기) |
| 스킬 `planning-coach` | 복귀 시 상태 브리핑 + 다음 할 일 제안 ("계속하자", "어디까지 했지") |
| `kit/` | 기획 방법론 페이로드 (core + packs) — 스킬이 내부적으로 사용 |

## 원리가 궁금하다면

이 플러그인은 planning-kit(기획자 × AI 페어 작업 킷)을 대화형으로 감싼 것입니다. 방법론 원문은 설치된 프로젝트의 `rules/methodology/README.md`, 킷 저장소의 `docs/`에서 볼 수 있습니다.
